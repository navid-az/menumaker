# Menomaker

**Menomaker** is a restaurant and café management system with a built-in, fully customizable QR-based digital menu builder.

It provides businesses with the tools to manage their operations, create engaging digital menus, and deliver a modern dining experience.

> 🚧 **Project Status:** Menomaker is currently under active development.

## Overview

Menomaker aims to become an all-in-one platform for restaurant and café management, helping businesses streamline their day-to-day operations while providing their customers with a seamless, interactive, and modern experience.

## Key Features

### Digital Menu

* Customizable digital menus
* Menu categories and items
* Global menu styling and color customization
* Configurable border radius and visual appearance
* Responsive design for mobile and desktop devices
* QR-code accessible menus
* Dedicated menu URLs
* Image support for menu items

### Business & Branch Management

* Business management
* Multiple branch support
* Branch-specific configuration
* Table management
* Menu management
* User authentication and authorization
* Feature-based access control

### Customer Experience

* Interactive digital menu
* Menu item search
* Table-based sessions
* Call waiter functionality
* Reservation support
* Online ordering capabilities
* Responsive mobile-first interface

### Real-Time & Operational Features

* Real-time operational updates
* Live order management
* Table sessions
* WebSocket-based communication
* Redis-backed real-time infrastructure

### Developer & Platform Features

* RESTful API architecture
* JWT authentication
* Server-side and client-side rendering
* Role and permission management
* Demo mode for showcasing the platform
* Dockerized development environment

## Project Goals

Menomaker is being developed with several goals in mind:

1. Provide restaurants and cafés with an easy-to-manage digital menu platform.
2. Replace static digital menus with interactive customer experiences.
3. Give businesses a centralized system for managing multiple locations.
4. Provide a scalable technical foundation for future SaaS functionality.
5. Explore modern full-stack web architecture, real-time communication, and responsive UI development.
